        0. Keep dashboard always running (do this once)

        Prevents "Cannot reach the dashboard server" after sleep, reboot, or code updates. Uses macOS KeepAlive — auto-restarts on crash and login.

        cd ~/Home-Repository
./scripts/install_dashboard_service_mac.sh

        After git pull, run Update and Open Dashboard.command or:

        cd ~/Home-Repository
./scripts/hard_restart_dashboard_mac.sh --pull

        Checking dashboard service…

        1. Enable automatic data refresh (recommended)

        Updates metrics after close (4:30 PM) and before open (6:30 AM).

        In Finder, open Home-Repository/scripts/ and double-click Enable Auto Refresh.command.

        If double-click does not launch, paste in Terminal:

        cd ~/Home-Repository
./scripts/install_ingest_schedule_mac.sh

        Checking schedule…

        2. Load your stock universe (once)

        Screen tab → Advanced → Load S&P 500, or run in Terminal:

        cd ~/Home-Repository
PYTHONPATH=src python3 scripts/manage_watchlist.py load-preset sp500

        Smaller list (SP100): load-preset sp100 · Special Watch: load-preset datacenter_us

        3. Daily workflow (recommended)

        In Finder, open Home-Repository/scripts/ and double-click:

        • Run End of Day.command — after close: ingest + screener + close report
        • Run Morning Prep.command — before open: screener + today's candidates
        • Run Refresh Live.command — right before you buy or sell (limit orders)

        Or paste in Terminal (replace ~/Home-Repository with your clone path):

        End of day — ingest + screener + close report (~15–30 min)

        cd ~/Home-Repository
./scripts/run_end_of_day_mac.sh

        Morning precheck — candidates for Trade tab

        cd ~/Home-Repository
./scripts/run_morning_prep_mac.sh

        Before buy/sell — live Finnhub quotes (Step 3)

        cd ~/Home-Repository
./scripts/run_refresh_live_mac.sh

        Check data freshness

        cd ~/Home-Repository
PYTHONPATH=src python3 scripts/manage_watchlist.py stats

        4. Individual steps (advanced)

        Use when you only need one piece. S&P 500 ingest takes ~15–25 minutes.

        After market close — quotes + today's bars only

        cd ~/Home-Repository
./scripts/run_ingest_mac.sh --after-close

        Before open — incremental ingest only

        cd ~/Home-Repository
./scripts/run_ingest_mac.sh --incremental

        Screener only (14 trading days)

        cd ~/Home-Repository
PYTHONPATH=src python3 scripts/run_period_screener.py --days 14 --save

        Large watchlists (100+ tickers): browser ingest is blocked — use Terminal commands above.
